Perlin Noise Flowfield

This visualization demonstrates a flowfield generated using Perlin noise — a type of smooth, natural-looking randomness often used in procedural graphics.

The canvas is divided into a grid where each cell contains a vector representing flow direction. These vectors change smoothly over time and space, creating an organic, evolving vector field.

Particles move through this flowfield by following the vector directions at their positions, creating intricate flowing trails that visualize the underlying noise field in motion.

The project uses p5.js with the noise() function to calculate flowfield vectors over a grid. Particles update positions by applying forces from these vectors and wrap around edges for continuous motion.

This approach explores smooth randomness and emergent complexity found in nature-like fluid simulations.
