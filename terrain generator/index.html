3D Terrain Generator

This demo generates an animated 3D terrain using Perlin noise. The sketch samples values from a 2D noise field, maps those values to vertex elevations in a mesh, and advances a noise offset over time to simulate flying across mountains and valleys.

  • Mesh: grid of vertices tessellated into triangles
  • Heights: map(noise(x, y), 0..1 → -height..+height)
  • Animation: moving noise offset ("flying") produces smooth motion
