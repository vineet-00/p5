L-System Fractal Tree

An L-System (Lindenmayer System) is a mathematical formalism used to simulate the growth processes of plant development and other natural forms. Starting from an initial seed string called the "axiom," rewriting rules iteratively expand this string, which is then interpreted as graphical commands to draw fractal structures like trees. This project generates a fractal tree by applying production rules and using turtle graphics to visualize recursive branching patterns with variable angles.
