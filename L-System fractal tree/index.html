L-System Fractal Tree

An L-System (Lindenmayer System) is a formal grammar originally devised to model plant growth. Starting from an initial seed string called the axiom, simple production rules iteratively replace characters to produce a longer sentence. That sentence is then interpreted by turtle graphics commands (move, rotate, save/restore state) to draw branching geometry.

This project uses a tiny axiom and one production rule to generate a fractal tree: short rules, repeated, produce complex, organic forms — exactly the sort of "finding things out" that Feynman loved.
