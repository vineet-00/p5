Mandelbrot Explorer

Imagine you’ve got a very simple rule: take a number, square it, then add another number. Do it again, and again. Now — some numbers stay calm forever, never running away. Others shoot off to infinity. If you mark the calm ones in black and the restless ones in color, a picture begins to appear: coastlines, spirals, galaxies. All from one little rule. The Mandelbrot set is like nature’s doodle, drawn with pure mathematics.

How it works: Every pixel on the canvas is a number. We repeat the formula z → z² + c. If it stays bounded after many tries, it’s part of the set (black). Otherwise, its escape speed gives us a color.
