Mandelbrot Set Visualization

The Mandelbrot set is a famous fractal defined by iterating the function z → z² + c in the complex plane. This visualization computes which complex points remain bounded (shown in black), with colors indicating how quickly unbounded points escape to infinity, revealing intricate and infinitely detailed patterns.
